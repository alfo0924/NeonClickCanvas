## 網站特點與優點

- **動態霓虹漸層背景**  
  背景自動以紅、橘、紫、深藍四種霓虹色彩平滑轉換，週期為15秒，色彩鮮明且極具未來感，營造出現代感十足的視覺體驗。

- **互動式幾何圖形生成**  
  使用者只要點擊畫面任一處，該位置就會出現隨機形狀、顏色的幾何圖形，包括圓形、方形、三角形、五邊形、六邊形、星形等，且每個圖形都帶有動態旋轉與位移效果。

- **累加與動態變化**  
  點擊次數越多，產生的幾何圖形數量與大小會同步增加，帶來豐富的互動回饋感。

- **自動重置與淡出動畫**  
  若5秒內沒有任何點擊，所有畫面上的幾何圖形會自動漸漸淡出消失，並重置累加計數，等待下一次互動。

- **自適應畫布**  
  畫布會自動隨瀏覽器視窗大小調整，確保無論在什麼裝置上都有最佳體驗。

## 玩法說明

1. **隨意點擊畫面**：每次點擊都會在該處產生隨機數量、隨機形狀、隨機顏色的幾何圖形。
2. **連續點擊**：點擊越多，產生的圖形越多、越大，讓畫面變得更加豐富熱鬧。
3. **觀察淡出**：如果停止點擊5秒，所有圖形會自動逐漸淡出，畫面回歸純粹的動態背景。
4. **再次互動**：淡出後可再次點擊，重新開始創造屬於你的幾何霓虹藝術。

## 程式碼邏輯與原理

**1. 動態漸層背景**
- 以一組顏色（紅、橘、紫、深藍）依序循環，每15秒完成一輪。
- 透過線性插值（lerp）計算當前時間點在兩個顏色間的中間色，並用 `fillRect` 填滿畫布，實現平滑過渡。

**2. 幾何圖形生成與管理**
- 每次點擊時，根據目前點擊次數，產生1~5個隨機幾何圖形，並隨機分配顏色、形狀、大小、旋轉角度與移動速度。
- 所有圖形以物件陣列方式儲存，每個圖形都包含位置、大小、顏色、型態、透明度、旋轉、縮放、速度等屬性。

**3. 動畫循環與互動**
- 透過 `requestAnimationFrame` 不斷重繪畫布，先畫背景，再畫所有圖形。
- 每個圖形在每幀都會根據自身速度移動與旋轉，並檢查是否超出邊界。
- 點擊時重設5秒計時器；5秒內沒點擊則觸發淡出模式。

**4. 圖形淡出與重置**
- 進入淡出模式時，所有圖形的透明度（opacity）每幀下降，直到完全透明後自動移除。
- 當所有圖形都淡出消失後，累加計數與淡出狀態自動重置，等待下次互動。

**5. 畫布自適應**
- 監聽視窗變化，自動調整Canvas大小，確保圖形與背景始終填滿整個畫面。

## 總結

這個網站結合了動態霓虹漸層背景與豐富的互動式幾何圖形生成，讓使用者能夠自由點擊創造屬於自己的霓虹藝術。其程式碼結構清晰，動畫流暢，互動回饋即時，並具備自動重置與淡出效果，適合作為創意展示、互動裝置或前端動畫學習範例。
